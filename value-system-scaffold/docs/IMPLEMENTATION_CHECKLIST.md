# VALUE Implementation Checklist

## Brokerage Identity

- [ ] Legal brokerage name configured
- [ ] Public brokerage name configured
- [ ] Broker of record verified
- [ ] State/license disclosures configured where required
- [ ] Years-serving-buyers statement verified
- [ ] Service area configured
- [ ] Contact information configured
- [ ] Logo/brand assets configured

## VALUE Language

- [ ] VALUE expanded correctly: Values · Alternatives · Learning · Uncertainty · Evidence
- [ ] Descriptor present: Human-centered homebuying decision support.
- [ ] Core line present: Price tells you what a home costs. VALUE helps you decide what that cost means to you.
- [ ] Buyer-remains-the-chooser language present
- [ ] No claims that VALUE selects the best house or guarantees better outcomes

## Buyer Experience

- [ ] Each buyer has individual identity/login
- [ ] Multi-buyer household/case linkage works
- [ ] Individual answers remain separately attributable
- [ ] Shared-view permissions are explicit
- [ ] Buyer can correct/update Decision Profile

## Journey / Showings / Decision Record

- [ ] Journey stage state works
- [ ] Showings can be added
- [ ] Property detail record works
- [ ] HBE/EBA observations distinguish fact/question/follow-up
- [ ] Comparables/evidence support source/date metadata
- [ ] Post-showing VALUE reflection works
- [ ] Stage decision aids work
- [ ] Living Decision Record persists revisions over time

## Internal Operations

- [ ] Time tracker enabled
- [ ] Travel separated from showing time
- [ ] Broker-support time can be captured
- [ ] Compensation model configured
- [ ] Alternative-model comparison available internally if participating in pilot/research
- [ ] Conflict Register configured to actual brokerage practices

## Security / Privacy

- [ ] Admin routes protected
- [ ] Buyer A cannot access Buyer B outside shared permissions
- [ ] Separate buyer credentials tested
- [ ] Sensitive documents use stronger authentication
- [ ] Upload file controls tested
- [ ] Logs checked for buyer-data leakage
- [ ] Retention/archive policy documented
- [ ] Backup/recovery tested

## Fair Housing / Legal / Ethics

- [ ] Federal Fair Housing review
- [ ] State protected-class review
- [ ] Local protected-class review
- [ ] State agency/brokerage law review
- [ ] Advertising/disclosure requirements reviewed
- [ ] Compensation language reviewed
- [ ] No subjective neighborhood steering fields
- [ ] No protected-class inference
- [ ] No persuasion/close-probability scoring

## EBA Intelligence

- [ ] Brokerage configuration loaded
- [ ] VALUE method loaded
- [ ] State/local knowledge separated from universal method
- [ ] Conflict rules loaded
- [ ] Buyer visibility rules enforced
- [ ] Revenue-neutral check tested
- [ ] Walk-away/wait scenarios tested
- [ ] Unsupported certainty tested
- [ ] Protected-class steering red-team completed

## Human Training

- [ ] Advisors understand VALUE purpose
- [ ] Advisors know how to use post-showing reflection
- [ ] Advisors distinguish observation from professional inspection conclusion
- [ ] Advisors understand buyer-owned Decision Profile
- [ ] Advisors understand Conflict Register
- [ ] Advisors know that a wise pause/walk-away can be success

## Go-Live

- [ ] Test household completed end-to-end
- [ ] Mobile experience tested
- [ ] Keyboard/accessibility tested
- [ ] Security boundaries tested
- [ ] Broker signs off
- [ ] Sentinel/integrity review completed
